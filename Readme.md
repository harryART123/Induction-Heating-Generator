# Induction Heating Generator
This repository is developed to be used as an example for learners with eager for science.
## Problem
The heating by induction is a technology that can work with renewable energy because this not demand higher consumption of electricity to reach high temperatures.
### Theoretical framework
The heating by induction is based on **Faraday's law** and **Foucault's current (eddy currents)** [1]. When an alternating current of high frequency goes around in a coil (inductor), it generates a variable magnetic field. Whether a conducting material is placed in this field, induced electric currents are generated inside; due to the material resistance, heat is released (Joule effect):
Key principles:
- **Electromagnetic induction**
- **Foucault's current (eddy currents)**
- **Skin effect**
- **Resonance**
